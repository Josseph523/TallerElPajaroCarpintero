# Project | Taller El Pájaro Carpintero | 

# ¿Qué significa este proyecto?

Elabore una página web que elabore utilizando una base de React y Tailwind CSS 
para un taller de carpinteria. En el que muestra opciones como inicio, información del negocio, galeria de imagenes, contacto
en el que se le muestra a todo publico de dispositivos moviles y computado

# ¿Qué herramientas use para elaborar este proyecto?
   React.js - Utilice una base creada de React que baje por internet, para tener la estructura de la pagina
   Tailwind css - utilice tailwind css para un estilo y diseño moderno
   Visual Studio Code - Para la elaboración del código principal
   HTML - CSS - JavaScript - Para toda la estructura y base de la pagina
   Git y GitHub – Para control de versiones, respaldo del proyecto y desplegar el proyecto

# ¿Qué realice exactamente?
    Creé un menú de navegación que cambia entre páginas sin recargar.
    Implementé una galería de imágenes que carga trabajos realizados del taller.
    Usé process.env.PUBLIC_URL para cargar imágenes correctamente al publicar.
    Ajusté estilos para que funcionen en dispositivos móviles.
    Solucioné problemas de rutas e imágenes rotas al subirlo a producción.
    Personalicé el diseño con animaciones y colores neutros.
    Acomodé las secciones para dispositivos moviles y computadoras.
